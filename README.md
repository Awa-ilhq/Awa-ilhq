<!-- ============================================================
  PANDUAN SNAKE ANIMATION (wajib agar ular tampil):
  1. Di repo Awa-ilhq, buat file: .github/workflows/snake.yml
  2. Isi dengan:

  name: Generate Snake
  on:
    schedule:
      - cron: "0 */12 * * *"
    workflow_dispatch:
    push:
      branches: [ main ]
  permissions:
    contents: write
  jobs:
    generate:
      runs-on: ubuntu-latest
      steps:
        - uses: Platane/snk/svg-only@v3
          with:
            github_user_name: ${{ github.repository_owner }}
            outputs: |
              dist/github-snake.svg
              dist/github-snake-dark.svg?palette=github-dark
        - uses: crazy-max/ghaction-github-pages@v3.1.0
          with:
            target_branch: output
            build_dir: dist
          env:
            GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}

  3. Buka tab Actions > "Generate Snake" > Run workflow, tunggu hingga hijau
  4. Setelah branch "output" terbentuk, gambar ular akan muncul otomatis
============================================================ -->
